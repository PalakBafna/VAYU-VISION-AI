# Vayu Vision AI — Business of AI Website

Static website for the Business of AI mid-semester assignment.

## Files
- `index.html` — main website
- `styles.css` — responsive visual design
- `script.js` — interactive perception pipeline

## Run locally
Open `index.html` in a browser.

For a local server:
```bash
python -m http.server 8000
```
Then open `http://localhost:8000`.
